# Intelli-Shield 2.0 创新竞赛答辩演示视频制作规范 (PRD)

## 一、 制作背景与目标
为了在创新创业竞赛路演与毕业设计答辩中实现最强烈的视觉反差，**不将对比逻辑耦合进正式生产级前端页面**，而是通过专门录制两套流水线的运行视频，在后期剪辑中制作**同屏双轨对照（Side-by-Side Comparison）**，直观征服评委。

---

## 二、 视频画面分屏与布局设计

- **分辨率**: 1920 × 1080 (16:9, 60fps)
- **画面分割**: 左右分屏对比（或画中画对比）
  - **左屏（45% 宽度，红灰冷色调）**: **“传统启发式规则（基线 1.0 / 老师 C++ 算法）”**
    - 顶部标签: `传统基线方案: 纯几何像素距离判定 (无认知/高虚警)`
    - 数据悬浮框: 实时统计【累计报警次数: 频繁】、【误报率: 87.5%】、【司机识别: 误判为行人】
  - **右屏（45% 宽度，蓝绿科技色调）**: **“Intelli-Shield 2.0: 双系统认知架构 (自研门控 + OmniJev)”**
    - 顶部标签: `本项目创新方案: System 1 毫秒级直觉 + System 2 数字安全员`
    - 数据悬浮框: 实时统计【时空门控: 过滤无效算力 73.5%】、【OmniJev 延迟: 107ms】、【误报率: 0.0%】
  - **中缝分割线**: 动态发光渐变条，标示 `VS 降维打击对比`

## 三、 五大标准演示测试用例（录制剧本）
### 用例 1: 驾驶员车载自撞排除（Driver Exclusion）
- **画面内容**: 叉车在通道内正常行驶，车厢内坐着驾驶员。
- **左屏（传统 1.0）**: 矩形框将司机识别为 person，计算司机到叉车距离为 0px，**瞬间触发刺耳警报（误报假阳性）**。
- **右屏（2.0 创新方案）**: 时空门控计算 IoP 包含度达标，打上标签 `[Driver Excluded]`，门控 SHUT，**保持 NORMAL 安全绿灯，无任何假警报**。

### 用例 2: 车辆熄火停驻静止对消（Motionless Cancellation）
- **画面内容**: 叉车熄火停放在车位上，几名地面工人在叉车旁 1 米处装卸搬运货物。
- **左屏（传统 1.0）**: 因人车距离极近，系统**全程红灯长鸣（造成现场工人的“警报疲劳/狼来了”效应）**。
- **右屏（2.0 创新方案）**: 时空门控检测到叉车连续静止 $\ge 3$ 帧，标记 `[Static Forklift]`，直接抑制探针调用，**绿色放行，保护算力**。

### 用例 3: 动态盲区与注意力涣散撞击（System 1 认知飞跃）
- **画面内容**: 叉车倒车加速驶向作业区，工人正背对车辆低头看手机，未佩戴反光安全帽。
- **左屏（传统 1.0）**: 叉车距离还较远时毫无反应，直到贴身 1 米才被动鸣笛，但工人已无法避让。
- **右屏（2.0 创新方案）**: 距离尚在 2.5 米时，门控激活 OmniJev 探针，单前向传导输出 `worker_awareness: unaware (0.85)` 与 `P(collision)=0.88`，**提前 1.5 秒发出 CRITICAL 破级警报，成功阻断事故**。

### 用例 4: 确定性安全工单闭环与数字孪生展示
- **画面内容**: 切入后台 Web 仪表盘（Digital Twin 与告警分析流水线）。
- **解说与特效**: 
  - 展示警报触发后，系统基于视觉探针结果秒级生成**确定性安全合规工单**（包含区域、违规行为判定、责任人绑定，无任何外部大模型幻觉与网络依赖）；

### 用例 5: 叉车三向红光物理防线与足底越界硬约束（Optical Red-Zone Breach）
- **画面内容**: 叉车在货车旁作业停顿或微调，投射出左/右/后三向高亮地表一字红光；一名穿反光背心的地面工人踩入红光线内侧 0.88 米处。
- **左屏（传统 1.0）**: 仅计算人体框中心与叉车中心距离，受高位视角倾斜与车辆暂歇静止对消影响，中心距显示 >250px，**错误显示 NORMAL 安全绿灯（致命漏报假阴性，人都在红线里了还不报警）**。
- **右屏（2.0 创新方案）**: 视觉感知层提取地表三向红光构建物理禁区，准确定位工人双脚接地点 $(841, 520)$，计算得出已越过红光线 -0.88m（`ZONE_INSIDE`），**物理一票否决瞬间触发 CRITICAL 红色爆闪**；同时探针显示工人分心背对 65%，给出高信息量归因解释。
